# Sistemas-complejos
Este repositorio contiene las prácticas de la materia Sistemas Complejos del segundo cuatrimestre de 2024, dictada por el Departamento de Física de la UBA. En esta asignatura se estudiaron métodos numéricos y prácticos para resolver aproximadamente y numéricamente ecuaciones diferenciales no lineales, principalmente en derivadas parciales, utilizando métodos Pseudo-Espectrales y PINN’s.
Los trabajos realizados fueron desarrollados en conjunto con mi compañero Facundo Urriste.
